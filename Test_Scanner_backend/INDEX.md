## ✨ КЛЮЧЕВЫЕ МОМЕНТЫ

### 3 ключевые точки использования ModelMapper:

**Точка 1:** В `UserMapper.toUserEntity()`
```
RegistrationRequest → User Entity (через modelMapper.map())
```

**Точка 2:** В `UserMapper.toLoginResponse()`
```
User Entity → LoginResponse DTO (через modelMapper.map())
```

**Точка 3:** В `AuthServiceImpl` методах
```
register() → использует userMapper.toUserEntity()
login() → использует userMapper.toLoginResponse()
refreshToken() → использует userMapper.toLoginResponse()
```

**Все 3 точки описаны в каждом документе!**
