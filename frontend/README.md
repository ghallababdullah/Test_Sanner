# СканПроверка Frontend

Production-oriented stack:

- React 19
- TypeScript
- Vite
- React Router
- TanStack Query
- Axios
- MUI
- Recharts
- React Hook Form
- Zod

## Start

1. Copy `.env.example` to `.env`
2. Set `VITE_API_BASE_URL`
3. Install dependencies
4. Run:

```bash
npm install
npm run dev
```
